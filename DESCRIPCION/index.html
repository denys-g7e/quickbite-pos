⚡

POS Rápido

Interfaz táctil optimizada para cobro express. Agrega productos en segundos con búsqueda instantánea.

🧠

Asistente IA

Integración con Groq AI. Consulta ventas, productos o genera reportes con lenguaje natural.

🖨️

Impresión Térmica

Ticket cliente + comanda cocina. Dos estaciones: Cocina (platos) y Barra (bebidas) con ESC/POS.

📊

Dashboard & Estadísticas

Ventas del día, top productos, métodos de pago, ingresos por hora, ticket promedio y más.

💵

Turno de Caja

Apertura y cierre con monto. Control de ingresos por turno con historial completo.

📄

Exportación SIN

Exporta ventas a formato SIN (XLSX + TXT) en ZIP. Listo para contabilidad boliviana.

🏷️

Happy Hour Inteligente

Reglas por categoría, producto o 2x1 con horarios y días configurables. Descuento automático.

🔔

Alertas Stock Bajo

Notificación visual cuando un producto está por debajo del umbral mínimo configurable.

👤

Clientes Frecuentes

Detección automática de visitas repetidas. Muestra "Cliente Frecuente" en POS con contador.

🛒

Delivery & Mesas

Soporte para servicio en mesa, para llevar y delivery. Divide cuentas y une mesas.

📦

Productos con Foto

Sube imágenes de productos desde el panel. Se muestran en el POS y ayudan al mesero.

🍳

KDS — Pantalla Cocina

Sistema de display para cocina con estados: pendiente → cocina/barra → listo → entregado.

✅ Características Completas

  • POS offline nativo con Electron + SQLite — sin internet, sin problemas
  • Impresión térmica con dos estaciones: Cocina (platos) y Barra (bebidas)
  • Asistente IA con Groq — pregunta en lenguaje natural sobre ventas, productos, etc.
  • KDS — Pantalla táctil para cocina con estados en tiempo real y polling 3s
  • Pago con QR — muestra código QR para pago electrónico
  • Dashboard con gráficos: ventas por hora, top productos, métodos de pago
  • Turno de caja con apertura/cierre y montos
  • Exportación SIN — XLSX + TXT en ZIP para contabilidad boliviana
  • Mapa de mesas — divide cuentas y une mesas fácilmente
  • Clientes frecuentes — detección automática de visitas repetidas
  • Alertas de stock bajo — notificación visual en dashboard
  • Happy Hour con reglas avanzadas por categoría, producto, 2x1 y horarios
  • Productos con foto — sube imágenes desde el panel
  • Sistema de usuarios: admin + empleados con PIN rápido
  • Exportación DB — respaldo y restauración de base de datos
  • Personalización: nombre, logo, color de tema, mensaje de agradecimiento
  • Modo demostración — banner "MODO DEMO" visible en POS
  • Notificación por correo — alerta al admin si no hay turno abierto
  • Inactividad con cierre de sesión automático configurable
  • Modo oscuro nativo — interfaz moderna y elegante

🔐 Seguridad

  • Sistema de activación por código único — protege tu inversión
  • Roles: Admin (control total) y Empleado (solo POS y pedidos)
  • Inicio de sesión con PIN rápido para empleados
  • Contraseñas hasheadas con bcrypt-12 rounds
  • Cierre automático por inactividad configurable
  • Base de datos local con WAL mode y encriptación de claves
  • Verificación de NIT válido para facturación boliviana
  • Auditoría de acciones: inicio sesión, cancelaciones, cambios de precio
